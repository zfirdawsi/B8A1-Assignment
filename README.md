# B8A1 Assignment: Problem Solving with TypeScript & OOP

## Overview

This repository contains my solutions for the B8A1 assignment, focused on problem-solving using TypeScript and Object-Oriented Programming (OOP).

The assignment covers eight problems designed to improve my understanding of TypeScript concepts and practical coding skills.

## Topics Covered

1. Functions and Optional Parameters
2. Union Types and Type Narrowing
3. Tuples and Readonly Properties
4. Generics and Rest Parameters
5. Interfaces and Array Filtering
6. Generics, keyof, and Indexed Access Types
7. Object-Oriented Programming and Inheritance
8. Promises and Async/Await

## Project Structure

- `solutions.ts` – Solutions to all eight TypeScript problems.
- `blog-1.md` – Understanding Type Narrowing in TypeScript.
- `blog-2.md` – Understanding Access Modifiers in TypeScript.
